### 🏥 [Clinica Medica API](https://github.com/wagnerquadros/clinica_medica_API)

> Full REST API for managing a medical clinic — doctors, patients, and appointments.

- **Auth:** Stateless JWT authentication, protected endpoints, public login only
- **Business rules:** Appointment validation (working hours, advance booking, conflict check, automatic doctor selection by specialty)
- **Data:** Soft delete for doctors and patients (`ativo` flag), versioned migrations with Flyway
- **Tests:** JUnit, MockMvc and Mockito
- **Docs:** Full Swagger/OpenAPI at `/swagger-ui.html`

`Spring Boot 4` · `Spring Security` · `Spring Data JPA` · `MySQL` · `Flyway` · `Lombok` · `Maven`
